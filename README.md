# Project Summary: Electronic Payment Trends in Kenya

Objective: Analyze transaction data from the Central Bank of Kenya to understand how digital and traditional payment methods have evolved.

Key Findings:
- Mobile money transactions increased by over 700% between 2013 and 2023.
- POS and debit card usage grew steadily, showing consumer adoption of digital payments.
- RTGS and EFT remained consistent, serving institutional needs.
- Correlation analysis revealed that mobile money, POS, and card payments move together, reflecting ecosystem maturity.

Skills Demonstrated:
Data cleaning, time series analysis, correlation analysis, data visualization (Pandas, Matplotlib, Seaborn).
